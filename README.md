# MINI PROJETO BACKEND ECOMMERCE
## ALUNO: Felipe Silveira Ribeiro - TURMA: Backend node v5

## Objetivo da aplicação: 
Criar uma estrutura simples de beckend, para um ecommerce, implementando os ensinamentos das aulas. Com as seguintes funcionalidades:
- Cadastro de cliente;
- Cadastro de produto;
- Criar carrinho;
- Atualização da lista de produto e de estoque;
- Listar - clientes, produtos e carrinho;
- Status de pedido;

## TECNOLOGIAS USADAS:
- javascript;
- nodejs;
- typescript;
## ESTRUTURA DOS ARQUIVOS
- types.ts
- cliente.ts
- produto.ts
- pedido.ts
- carrinho.ts
- functions.ts
- main.ts
